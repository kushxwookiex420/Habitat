# Spark Quick View
A starter Android companion widget that displays the latest relevant Spark Driver notification text.

Limitations: no private offer-feed access, no scraping, no offer acceptance/rejection. It can display only details Android exposes in Spark notifications. Home-screen widget only; Samsung lock-screen/AOD support is not guaranteed.

Build with GitHub Actions: open the Actions tab and run "Build Spark Quick View APK". Download the APK artifact from the successful workflow run.
